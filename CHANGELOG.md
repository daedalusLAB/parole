| **Prosody is no longer invented where Praat measured nothing** – `process_prosody.R` used to fit a single cubic spline (`splinefun`, fmm) through all the non-`NA` points of each track and then evaluated it at *every* frame timestamp, so silences and the edges of the clip received numbers (`splinefun` cannot turn extrapolation off: it rejects the `extrapolation` argument, tested). On top of that, `df_final$pitch[df_final$pitch < 10] <- 0` turned "not measured" into a plausible 0 Hz. Each track is now split into contiguous spans and interpolated linearly **inside** a span only (new `scripts/prosody_align.R`, `MAX_GAP_S = 0.1 s`, `MIN_TRACK_POINTS = 2`); outside a span the value is `NA`, and Praat's `mute` pitch candidate (`frequency = 0`) becomes `NA` instead of 0 Hz. New `voice_present` column marks the frames that actually have a tracked pitch.
